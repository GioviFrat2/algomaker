# AlgoMaker

Mini web app ispirata a Flowgorithm che gira interamente nel browser (anche in locale).

## Funzionalità

- Creazione flow a blocchi (Start, Input, Process, Decision, Output, End)
- Riordino ed eliminazione dei blocchi
- Generazione automatica di pseudocodice
- Salvataggio automatico in `localStorage`
- Import/Export JSON

## Avvio in locale

Puoi aprire direttamente `index.html` nel browser.

In alternativa, con Python:

```bash
python3 -m http.server 8080
```

e aprire `http://localhost:8080`.
